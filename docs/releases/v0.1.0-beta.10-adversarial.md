# Ronda adversarial de identidad, outcome y handoff (`v0.1.0-beta.10`)

## Alcance

Gate documental pre-code de ADR-0022, ADR-0023, ADR-0024 y el spike del
2026-08-08. Ataca identidad project/store, bootstrap concurrente, autoridad de
CURRENT, evidencia durable, inspect/retry, checkpoint gobernado, resume por una
revisión y compatibilidad de planes v1. Esta ronda todavía no certifica una
implementación ni autoriza tag/publicación.

## Modelo de amenazas

La memoria y los inputs de checkpoint son datos no confiables. Un timestamp,
JSON de authority o texto que describe Git no prueba observación. La pérdida de
una respuesta no puede convertir ausencia de journal en certeza; archivos live
no pueden autocertificar fsync; cambiar rutas no cambia identidad lógica y
cambiar identidad no puede continuar una cadena por accidente.

## Verificación de canonicidad / determinismo

- `write-plan-v1` y `write-planning-result-v1` no incorporan UUID ni cambian;
  transaction-attempt liga plan, base y txid por separado.
- Project/store identity, intents, receipts, planes y checkpoints usan JSON
  canónico, claves exactas y hashes explícitos.
- Inspect sólo eleva durability con receipt que prueba operaciones anteriores;
  legibilidad de journal no reinterpreta un fallo.
- Resume fija una revisión y conserva ranking; working_state no entra a FTS.
