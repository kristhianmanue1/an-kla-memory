# `v0.1.0-beta.14`

Beta.14 publica las mejoras de adopción integradas después de beta.13. El
primer write gobernado ya no exige descubrir el recorrido leyendo el código:
la CLI identifica los schemas y entradas, y la guía documenta de extremo a
extremo cómo construir, ligar, planificar y confirmar una escritura.

El contexto gestionado y la plantilla administrada permanecen en
`0.1.0-beta.11`. Esta release no cambia almacenamiento, schemas, política de
escritura, autoridad ni el contrato `plan-write → commit-write-plan`.

## Cambios principales

- Ayuda ampliada para `plan-write` y `commit-write-plan`, con schemas exactos,
  revisión esperada y avance secuencial de `CURRENT`.
- Recorrido completo del primer write: propuesta, digest JSON canónico,
  configuración saneada del issuer, `configuration_fingerprint`, autoridad,
  planning result y commit.
- Errores de lectura/parseo JSON identifican el rol saneado (`proposal`,
  `authority` o `planning_result`) sin exponer rutas, payloads ni secretos.
- `write_plan_base_changed` señala la recuperación operable: releer `status` y
  volver a crear propuesta, autoridad y plan contra la nueva revisión.
- Estado documental posterior a beta.13 consolidado, incluidas las fronteras
  de AN-KLA como memoria no autoritativa y el handoff de G-FRESH.

## Compatibilidad y límites

- Actualización directa desde beta.13 sin migración física ni actualización de
  contexto gestionado.
- Stores anteriores siguen sujetos a las rutas de migración ya documentadas.
- No genera automáticamente `proposal` ni `authority`; esa decisión permanece
  abierta en el issue #71 y no forma parte de beta.14.
- No existe paquete PyPI ni artefacto adjunto: la distribución continúa desde
  una etiqueta Git exacta.
- Python 3.9 o posterior; sin dependencias Python de runtime.
- GitHub Actions no puede iniciar mientras la cuenta tenga agotado el crédito;
  el gate efectivo queda documentado con CI local simulada y wheel aislado.

## Instalar o actualizar

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install --upgrade \
  "an-kla-memory @ git+https://github.com/kristhianmanue1/an-kla-memory.git@v0.1.0-beta.14"
.venv/bin/python -m an_kla --version
.venv/bin/python -m an_kla --project-root . context status
.venv/bin/python -m an_kla --project-root . verify
```

La versión esperada es `an-kla-memory 0.1.0b14`; `context status` conserva
`template_version: "0.1.0-beta.11"`.
