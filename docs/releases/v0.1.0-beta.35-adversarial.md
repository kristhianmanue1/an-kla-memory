Artefacto atacado: diff `v0.1.0-beta.34..main@64def20` (delta de producto
#181/#186/#187/#188, ADR-0059/0060/0061, hooks idempotentes + runner optativo

diff; ningún reporte ni acta del preparador fue consultado antes del

## Modelo de amenazas

Frontera memoria-no-es-instrucción intacta. Frentes propios: (a) que el lock
delta y el gate acotado introduzcan esperas nuevas sin deadline o inviertan
órdenes; (b) que las proyecciones de linaje (ADR-0061) sirvan metadatos no
validados (falsa ausencia o falsa presencia de candidatos); (c) que la
re-escritura de `candidate_relation`/`valid_identity_receipt` cambie
clasificaciones para stores sanos o tape diferencias en stores rotos;
(d) que la matriz rc=3 cambie códigos de salida observables sin declararlo;
(e) que los pins o la nota afirmen un estado que no es el real.
