# `v0.1.0-beta.15`

Beta.15 publica el diagnóstico de arranque por ejes observables (#76/#83),
la corrección de la suite bajo `jsonschema` ausente (#81), la regla
documental de worktrees (#77), la sincronización de ADR-0036 con la
implementación real y la red de resguardo del CLI ante excepciones no
previstas (#84).

El contexto gestionado y la plantilla administrada permanecen en
`0.1.0-beta.11`. Esta release no cambia almacenamiento, schemas de
escritura, política de autoridad ni el contrato
`plan-write → commit-write-plan`.

## Cambios principales

- Comando `startup-diagnostic` (ADR-0036, schema
  `an-kla/startup-diagnostic-v1`): clasifica `store_presence`,
  `store_integrity`, `identity` y `repo_context` antes de trabajo
  material; distingue "proyecto nuevo" de "worktree sin memoria" sin
  descubrir ni adoptar nada. Éxito (exit 0) en todo caso diagnosticable.
- Red de resguardo del CLI (#84): una excepción no prevista responde
  `an-kla error: cli_unexpected_failure` con exit 1, sin traceback ni
  rutas absolutas por stderr. El traceback completo va a un log local
  privado `0600` (`~/.cache/an-kla/cli-errors.log`, convención XDG, tope
  5 MB, política reset). `AN_KLA_DEBUG=1` restaura el traceback en stderr
  para desarrollo; `AN_KLA_NO_CLI_ERROR_LOG=1` desactiva el log.
  `capabilities()` declara `cli_error_surface`.
- ADR-0036 sincronizada con la implementación: estado aceptada,
  mecanismo de `repo_context` fiel al código (`git rev-parse --git-dir`
  vs `--git-common-dir`, timeout, `GIT_*` saneado) e historia completa
  del refinamiento; registro de ADRs y recuentos actualizados (33/3).
- `jsonschema` declarado como extra de test (#81): la suite no rompe
  cuando el paquete está ausente.
- Documentación: los worktrees no inicializan memoria propia (#77); cada
  invocación desde un worktree apunta al checkout canónico.

## Compatibilidad y límites

- Actualización directa desde beta.14 sin migración física ni actualización
  de contexto gestionado.
- El resguardo del CLI cubre lo que antes era crash indefinido; los
  códigos y exit codes ya publicados no cambian.
- `KeyboardInterrupt` sigue imprimiendo traceback (interactivo,
  preexistente; fuera del alcance de #84).
- No existe paquete PyPI ni artefacto adjunto: la distribución continúa
  desde una etiqueta Git exacta.
- Python 3.9 o posterior; sin dependencias Python de runtime
  (`jsonschema` es extra de test).
- GitHub Actions no puede iniciar mientras la cuenta tenga agotado el
  crédito; el gate efectivo queda documentado con CI local y wheel
  aislado.

## Instalar o actualizar

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install --upgrade \
  "an-kla-memory @ git+https://github.com/kristhianmanue1/an-kla-memory.git@v0.1.0-beta.15"
.venv/bin/python -m an_kla --version
.venv/bin/python -m an_kla --project-root . startup-diagnostic
.venv/bin/python -m an_kla --project-root . context status
.venv/bin/python -m an_kla --project-root . verify
```

La versión esperada es `an-kla-memory 0.1.0b15`; `context status` conserva
`template_version: "0.1.0-beta.11"`.
