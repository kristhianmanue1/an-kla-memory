## Modelo de amenazas

La candidata añade una superficie de error nueva (catch-all del CLI): un
handler mal hecho habría introducido la fuga que dice impedir. Ese riesgo
se atacó con ronda propia de dos pasadas
(`docs/planning/issue-84-resguardo-cli-adversarial-2026-08-20.md`,
fix-and-retry → proceed) con e2e por subprocess real. La memoria y sus
proyecciones siguen siendo datos no confiables; nada de esta release
eleva autoridad recuperada.
