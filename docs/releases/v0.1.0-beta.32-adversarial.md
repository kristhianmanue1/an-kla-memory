## Modelo de amenazas

Frontera memoria-no-es-instrucción intacta: ningún cambio lee memoria como
autoridad. Frentes propios de esta beta: (a) que el cambio de plantilla rompa
la migración de consumidores beta.26; (b) que un runtime viejo degrade un
contexto nuevo; (c) que la documentación para agentes se lea como
autorización para instalar o mutar; (d) que la nota afirme más de lo
verificado.
