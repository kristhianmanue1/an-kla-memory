1. **¿El wheel corresponde realmente al candidato?** Sí — build de la
   ronda desde el working tree del candidato (código final), sin red ni
   instalación editable. SHA-256 abajo. El wheel a tagear/publicar se
   reconstruye desde el commit candidato y debe verificarse
   content-idéntico antes de usarlo (regla beta.25/26: ningún cambio
   silencioso sobre un candidato sellado).
2. **¿El versionado del paquete reporta beta.27?** Sí — `an-kla --version`
   → `an-kla-memory 0.1.0b27`; `capabilities` → `product.version`
   `0.1.0b27` (operador + atacante R2 misión 1).
3. **¿Se confundió package version con `TEMPLATE_VERSION`?** No — verificado
   por R1 (F-R1-3/4): `TEMPLATE_VERSION` sigue en `0.1.0-beta.26`
   (`context_text.py` y fixtures byte-idénticos al tag anterior); ningún
   documento afirma lo contrario. Upgrade desde beta.26 sin
   `context update`.
4. **¿El repro de #133 funciona desde el wheel instalado?** Sí — atacante
   R2 (black-box, sin leer código): siembra gobernada con
   `plan-write --emit-authority-template` (cero fricción, F-R2-004) y
   `retrieve 'skopos patch parser pendiente'` → `retrieval-result-v3` +
   `empty_reason: "no_lexical_overlap"` + `zero_score: 3`; contraste con
   solape → v1 sin señal; paridad scan↔fts5 por CLI con diff de sólo 2
   líneas de perfil (misión 5); el payload valida contra
   `retrieval-result-v3` con jsonschema.
5. **¿Las notas prometen más de lo demostrado?** No tras absorber F-R1-2:
   la aritmética de suite quedó con provenance correcta (baseline 1028 +
   20) y la ejecución runtime es dato del operador (corrida completa:
   **1048 tests OK**, 5 skips). No se atribuyen cambios de plantilla,
   G3/#57 ni generadores (#71 abierto).
6. **¿La instalación documentada funciona?** Patrón `pip install @ tag`
   ejercitado contra el wheel local; reverificación post-publicación
   registrada después del tag (límite declarado).
7. **¿Algún BLOCKER/HIGH reproducible pendiente?** No — F-R1-1 (acta
   ausente, bootstrap esperado) y F-R1-2 (aritmética) absorbidos; el resto
   de hallazgos son LOW/INFO (F-R1-9 estado cosmético del ADR ya
