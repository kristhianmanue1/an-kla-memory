# AN-KLA Memory v0.1.0-beta.6

Versión del código: `0.1.0b6`. Etiqueta de distribución: `v0.1.0-beta.6`.

## Resumen

Release correctivo del contrato administrado: elimina la duplicación del
bloque `upgrade inspect` introducida accidentalmente en beta.5 e integra el
párrafo `target_drift` + `rebuild-index` en el flujo canónico del *Protocolo
de actualización* de `AN-KLA.md`.

## Defecto corregido

### Duplicación del bloque `upgrade inspect` en `DETAILED_CONTRACT` (beta.5)

`AN-KLA.md` (líneas 68-71 y 80-83 en beta.5) contenía dos bloques idénticos:

```bash
python3 -m an_kla --project-root . upgrade inspect \
  --target <etiqueta-exacta-instalada>
```

con el párrafo `target_drift` intercalado. Defecto cosmético pero vivo en el
contrato redistribuido a todos los consumidores.

**Fix:** se elimina la segunda ocurrencia. El párrafo `target_drift` se
integra en el párrafo "Revisa el plan y conserva su `plan_fingerprint`…",
justo antes del bloque `apply`. Se añade `[--confirm-target-drift]` al
comando `apply` y se incorpora `rebuild-index` al flujo canónico.

### Test anti-regresión

`tests/test_context_package.py::test_detailed_contract_has_no_duplicated_code_blocks`
asegura que ningún bloque de código (fenced) aparezca más de una vez en
`DETAILED_CONTRACT` por contenido.

## Cambios de contrato

- `TEMPLATE_VERSION = "0.1.0-beta.6"`. `content_sha256` sin cambios;
  `contract_sha256` cambia por la reorganización del *Protocolo de
  actualización*.
- `0.1.0-beta.5` registrada en `_KNOWN_CONTEXT_TEMPLATES` con su hash real
  (`sha256:48596b9e…`).

## Migración desde beta.5

```bash
.venv/bin/python -m pip install --upgrade \
  "an-kla-memory @ git+https://github.com/kristhianmanue1/an-kla-memory.git@v0.1.0-beta.6"
.venv/bin/python -m an_kla --version
.venv/bin/python -m an_kla --project-root . context status
.venv/bin/python -m an_kla --project-root . upgrade inspect \
  --target v0.1.0-beta.6 > /tmp/plan.json
.venv/bin/python -m an_kla --project-root . upgrade apply \
  "$(jq -r .plan_fingerprint /tmp/plan.json)" --plan /tmp/plan.json
.venv/bin/python -m an_kla --project-root . upgrade verify --target v0.1.0-beta.6
git diff -- AGENTS.md AN-KLA.md
```
