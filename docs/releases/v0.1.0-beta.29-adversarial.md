## Afirmaciones a falsar

1. Un JSON `channel_confirmed` no puede planificar ni confirmar checkpoint
   por CLI o API, incluso con un plan anterior.
2. El flujo `model_derived` sigue completando template → plan → commit.
3. El wheel instalado declara `0.1.0b29`, contiene los recursos esperados y
   corresponde al commit finalmente etiquetado.
4. Documentos, tag propuesto y runtime coinciden; la plantilla gestionada
   permanece en beta.26.

pre-tag indicadas arriba. El tag no demuestra instalación en el consumidor.
