# `v0.1.0-beta.13`

Beta.13 entrega G-VIEW v1 (issue #60 / ADR-0032 y ADR-0034): una vista
contextual derivada, determinista, read-only y non-authoritative sobre una
revisión AN-KLA fijada. Organiza afirmaciones por `subject_ref`, expone
conflictos completos y nunca convierte memoria en instrucciones o autoridad.

El contexto gestionado y la plantilla administrada permanecen en
`0.1.0-beta.11`; esta release no modifica `AGENTS.md` ni `AN-KLA.md`.

## Cambios principales

- Core `context_view()` compartido, sin reloj, red, Git ni `CURRENT` implícito.
- CLI `view context --revision sha256:...` con JSON canónico y exits estables.
- MCP `an_kla_view_context` con el mismo payload en `content[0].text` e
  `isError` para la unión cerrada de errores.
- `capabilities()["view"]` descubre contrato, superficies, proyecciones,
  límites, warnings, errores y pureza L2 sin leer memoria.
- Proyecciones `metadata`, `text` (default) y `full`; `full` exige un
  `subject_filter` exacto.
- Paginación atómica por subject y errores recuperables con presupuesto mínimo
  exacto cuando un subject o el envelope no caben.
- Reader coordination: puede crear o bloquear `.reader-gate`, sin mutar el
  sustrato de afirmaciones ni adquirir `.write.lock`.
- Schemas instalados `an-kla/context-view-v1` y `an-kla/view-error-v1`.

## Frontera de confianza

La salida declara `canonicality=non-authoritative`,
`untrusted_memory_data=true`, `live_revalidation_performed=false` y exige
revalidación contra fuentes canónicas antes de actuar. `record_text` y
`record_raw` siguen siendo datos potencialmente hostiles.

## Compatibilidad y límites

- Lee stores beta.12 sin migración física y conserva la revisión exacta.
- Sin cache persistente, ganador autoritativo, consulta de fuentes vivas ni
  autenticación criptográfica del cursor.
- Python 3.9 o posterior; sin dependencias Python de runtime.
- CI remoto no ejecutable mientras los créditos mensuales de GitHub Actions
  estén agotados; el gate efectivo es CI local simulado y auditoría de wheel.

## Instalar o actualizar

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install --upgrade \
  "an-kla-memory @ git+https://github.com/kristhianmanue1/an-kla-memory.git@v0.1.0-beta.13"
.venv/bin/python -m an_kla --version
.venv/bin/python -m an_kla --project-root . verify
.venv/bin/python -m an_kla capabilities
```

Resuelve una revisión exacta con `verify` y pásala a:

```bash
.venv/bin/python -m an_kla --project-root . view context \
  --revision sha256:<64hex>
```
