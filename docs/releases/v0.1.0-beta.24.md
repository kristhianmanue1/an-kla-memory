# v0.1.0-beta.24 — Checkpoint first-try para agentes (2026-09-06)

Etiqueta: `v0.1.0-beta.24` · Versión: `0.1.0b24` · Base: `559040e`.
**Release code-only**: contrato gestionado y `TEMPLATE_VERSION` siguen en
`0.1.0-beta.21`.

## Contenido

1. **Checkpoint first-try para agentes** (issues #120.2/.3/.4 y #121):
   - `checkpoint plan --emit-authority-template`: emite la plantilla de
     `checkpoint-authority-v1` con `proposal_sha256`/`base_revision`
     calculados desde el proposal interno — el agente ya no replica el
     armado a mano. Read-only y determinista.
   - `--input`/`--authority` documentados en `--help`: `--input` espera el
     **working_state-v2 directo** (`checkpoint-proposal-v1` describe el
     objeto interno); `--authority` opcional (falta →
     `missing_checkpoint_authority`, exit 2).
   - `docs/agent-checkpoint-guide.md`: cierre de sesión gobernado
     end-to-end (forma de `--input`, binding, clases de autoridad y
     attest, errores comunes, worktrees), validado e2e antes de publicar.
2. **Documentación de instalación/actualización más fiable para agentes**:
   - Aviso de update-check apunta al flujo completo de actualización
     (`context plan --operation update`, `docs/uso-diario.md`).
   - `docs/upgrade-agent-flow.md` refrescado (ejemplos vigentes, enlace
     recíproco con uso-diario).
   - "Ruta del agente": mapa de documentación en `docs/README.md`.

También incluye la aceptación de **ADR-0048** (G3, store_root externo —
sin implementación aún) y el fix **#119** ya publicado en beta.23.
