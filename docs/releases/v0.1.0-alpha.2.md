# AN-KLA Memory v0.1.0-alpha.2

> Nota prospectiva: este tag conservó por error `version = "0.1.0a0"` en
> `pyproject.toml`. La deriva se corrige y queda cubierta por CI desde alpha.3;
> el contenido histórico de este tag no se reescribe.

Fecha: 2026-08-01

## Incluye

- Servidor MCP local de sólo lectura por `stdio` (`python3 -m an_kla.mcp`).
- Recuperación MCP con presupuesto exacto del bloque UTF-8 que recibe el modelo.
- Datos recuperados marcados como no confiables y diagnósticos saneados.
- Pruebas de contrato MCP, transporte `stdio`, lector persistente y reemplazo
  de `CURRENT`.
- CI para Linux, macOS y Windows con Python 3.9 y 3.12.
- Perfil de durabilidad visible en `verify` y `doctor`.

  ejecución (Linux, macOS y Windows; Python 3.9 y 3.12).

## Límites conocidos

- MCP sólo lectura; no hay consolidación ni escritura desde IDE.
- Sólo se admite MCP `2025-11-25`.
- La recuperación es `scan-fallback/v1`; no representa aún el perfil IDF o
  híbrido evaluado como siguiente fase.
- En Windows, `windows-no-dir-fsync/v1` no promete la misma persistencia ante
  caída súbita que `posix-fsync-dir/v1`.
- El ejemplo de VS Code es opt-in y admite una sola raíz de proyecto.
